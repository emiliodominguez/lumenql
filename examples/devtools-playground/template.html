    Refetch the listThe live query refetches; the panel shows a network operation.

    Same query twiceTwo calls, one request: the second result's source is dedupe.

    query Todos · fetchPolicy: network-only × 2

    Optimistic add that failsThe row appears at once, the server rejects it, the layer rolls back.

    mutation AddTodo($title: String!) · optimistic + invalidates ["todos"]

    Flaky endpointThe server answers 503 twice; the client retries with backoff.

    query ServerHealth { health { region latency } } · retry: 2

    Stream a deployA subscription over Server-Sent Events, one result per step.

    subscription Deploys { deploy { step status } }

    InvalidateDrops the cached list; the live query refetches it.

    client.invalidate(["todos"])
